# Projeto Convert

Aplicação de conversão de moedas desenvolvida com o objetivo de aplicar boas práticas em desenvolvimento front-end. O sistema permite que o usuário insira um valor em Real Brasileiro (BRL) e obtenha a conversão instantânea para Dólar Americano (USD), Euro (EUR) ou Libra Esterlina (GBP).

## Funcionalidades

*   **Entrada de Valores:** Campo numérico estruturado para a inserção do valor que será convertido.
*   **Seleção de Câmbio:** Menu de seleção dinâmico contendo as principais moedas internacionais: Dólar, Euro e Libra.
*   **Cálculo e Feedback Instantâneo:** Processamento dos valores em JavaScript com exibição clara do resultado formatado na tela para o usuário.

## Tecnologias Utilizadas

*   **Front-end:** HTML5, CSS3 e JavaScript (ES6+)
